   - Créer les acteurs : Utilisateur, Administrateur, Système Externe, etc.
   - Placer dans le package 'Cas d Usage'
   - Rapporter l'UUID de chaque acteur

3️⃣ **Créer les Cas d'Usage** : Utiliser les outils MCP

   - Rapporter l'UUID de chaque cas d'usage
   - 🚨 OBLIGATOIRE : pour chaque cas d'usage lié à une exigence, matérialiser le lien «Satisfait» avec l'outil MCP
     `analyst_createRelation` (relation_type="satisfy", source_uuid=<UUID du cas d'usage>, target_uuid=<UUID de l'exigence>,
     module_name="ModelerModule") en un seul appel.

4️⃣ **Créer les Associations Acteur-Cas d'Usage** : Utiliser les outils MCP

   - Utiliser les types d'association appropriés

   - Maintenir la traçabilité vers les exigences
